## 一句话总览

注册登录、Create 生成、发布、Home/Explore 浏览和 Play 远端加载**全部端到端打通**，可在 `docker compose up` 后离线复现。当前主链路还包含 revision、remix、Memory、可靠投递和实时 SSE 增量；模型、ClamAV、Sentry、OpenTelemetry 等外部能力仍通过开关启用，默认保持离线可跑。

## 1. 已完成（可现场验收）

### 登录注册 Auth
- 邮箱注册 / 登录 / 退出；bcrypt 密码哈希 + HttpOnly/SameSite JWT Cookie；前端不保存 token，刷新时由 `GET /auth/me` 恢复会话。认证库仍复用同步 SQLAlchemy，但 DB 查询、bcrypt 与清理 I/O 全部进线程池，不阻塞 ASGI 事件循环。
- 受保护资源前后端双重守卫：后端 `Depends(get_current_user)`，前端 `/create`、`/me` 未登录重定向。
- 账号自助：改密、改资料、删号；登录校验 `is_active`；注册/登录 Redis IP 限流。
- **OAuth（加分）**：Google + GitHub **真实授权码流程**（`/auth/oauth/{provider}/start`+`/callback`）、`OAuthAccount` 账号绑定/合并 upsert、provider 探测；state 有时效并绑定浏览器 HttpOnly Cookie。未配置 provider 时默认禁用；固定共享身份的 demo 仅可通过 `ENABLE_OAUTH_DEMO=true` 在本地显式开启。

### 主页 Home
- 数据全部来自后端 `GET /games`（按 `status=PUBLISHED` 过滤），**非前端写死**（仅离线兜底数组）。
- 卡片字段齐全：封面 / 标题 / 作者 / 简介 / 标签 / 发布时间 / 播放数；**Create 来源游戏显示「✨ AI」角标**。
- 搜索、标签筛选、排序、「AI Generated」筛选；游戏详情页；点赞、收藏、播放次数统计。
- 测试数据：3 个已发布示例游戏，其中 **火线突围由真实 Create 流水线生成**（`source=create`；具体模型由 `MODEL_NAME` 决定），满足「≥3、≥1 来自 Create」。

### 游玩 Play
- 按 DB meta 从对象存储（MinIO）**远端加载 `manifest.json` + bundle**，`iframe` 沙箱运行；接口返回 `_source:"oss"` / `oss://...` 可证明来自远端。
- 四态齐全：加载中 / 成功 / 失败（错误页 + 重试，非白屏）/ 退出（返回首页 / 重开）。
- 埋点：播放计数（30 分钟防刷）；游戏内 `postMessage` 上报分数 → 排行榜。

### 创建 Create（核心）
- 多模态输入：自然语言创意 + 文件/图片/视频上传，素材在生成任务中被引用（`asset_processing` 节点生成素材清单）。
- **Multi-Agent：LangGraph 固定状态图（24 功能节点 + `failed`/`done`）**，包含 `memory_retrieval`、生成主链、`project_build`、`build_validation`、玩法 QA、repair/replan、revision/remix 和 `memory_update`；repair / replan 通过条件回边控制，非单次黑盒调用。
- **Revision / Remix**：`POST /tasks/{id}/revise` 和 `POST /games/{id}/remix` 已接入；任务以不可变的 `base_game_id + base_version` 为基线，发布新版本或派生新 Game，并校验并发版本冲突。
- **LangGraph 节点级持久化**：生产使用官方 `PostgresSaver`，worker 崩溃从最新检查点继续；Retry 从失败节点 replay，`from_scratch` 可显式清空 thread 全量重跑。
- 任务状态 `pending/running/succeeded/failed` + 当前步骤；每步 `AgentStep` / `AgentLog` 持久化。Worker/API 提交后通过 Redis Pub/Sub 发布轻量失效信号，FastAPI 重新读取 PostgreSQL 真源并经 SSE 推送完整快照，前端实时展示步骤流、活动日志和 token 计数；断线时指数退避重连并保留 30 秒低频兜底。
- 产物上传 OSS（`games/{id}/v1/`）+ 写 `manifest.json` + `Game`/`GameVersion` 入库；生成后可预览，发布后上首页。
- 加分：任务历史、失败重试、2D/3D 选择、生成成本（token）统计。

### 工程基础设施
- 远端产物协议 `game-manifest/v1`：`schema_version / entry / files[{path,url,sha256}] / permissions`。
- 安全/隔离：生成阶段由独立 `sandbox` 服务运行 Playwright/Chromium（只读文件系统、tmpfs、CPU/内存/PID 限制、默认无外网路由，可选 gVisor）；Play 阶段使用无 `allow-same-origin` 的 iframe 和带时效的 API 文件 token。生成代码还要通过静态规则、V8 预检、构建和玩法 QA；上传会做 MIME 嗅探、图片重编码/EXIF 清理、ZIP 炸弹约束，并可选 ClamAV 扫描。
- 数据库 PostgreSQL + SQLAlchemy + **Alembic 迁移**（`create_all` 兜底）。
- 测试/CI：`backend/tests` pytest（auth/games/tasks/uploads/social/限流）+ GitHub Actions（后端 pytest + 前端 `tsc`）。
- 部署：`docker compose`（web/api/worker/postgres/redis/minio）+ 生产 compose + Zeabur 指南 + 可选整站密码门禁。

## 2. Mock / 简化的部分（边界已预留，可平滑替换）

| 项 | 现状 | 边界 |
| --- | --- | --- |
| 服务端生成沙箱 | Compose 默认启动独立 Playwright/Chromium `sandbox`；生产可将 `SANDBOX_RUNTIME=runsc` 切到 gVisor。裸跑测试或显式 `SANDBOX_REQUIRED=false` 时才允许进程内 V8 降级 | `sandbox` API 已固定，仍需按部署环境验证 Chromium 自身沙箱和 gVisor 可用性 |
| 内容审核 / 病毒扫描 | 文本审核默认 `blocklist + log`，可切 `MODERATION_MODE=enforce` 或 `MODERATION_PROVIDER=llm`；ClamAV 通过 `UPLOAD_SCAN=clamav` profile 启用 | 第三方审核和病毒库不是仓库内置，生产需单独部署和监控 |
| 模型链路 | 默认 `USE_REAL_MODEL=false` 离线运行启发式/mock；`true` 使用 OpenAI 兼容模型。`CODE_AGENT_ENABLED`、`CODE_AGENT_AUTHOR_ENABLED` 分别控制修复工具循环和 2D 有界作者团队 | 模型供应商、key 和预算由环境变量控制；失败仍回到确定性门禁 |
| 视频素材 | 仅存储 + 引用，未做抽帧理解（图片可进 vision） | 素材清单已含 `kind`，可加抽帧节点 |
| OAuth | 代码完整；默认未填密钥时禁用，开发环境可显式开启 demo | 填 client id/secret 即真授权；生产强制关闭 demo |
| 播放计数 | 同步写 DB | 可改异步事件聚合 |

- **沙箱纵深**：gVisor、Chromium seccomp/user namespace 需要宿主机能力，Compose 默认值不能替代生产安全评审。

## 4. 再给 1 周的迭代计划

1. **生产隔离加固**：在具备条件的宿主机启用 gVisor/Chromium seccomp，并建立 sandbox 资源与错误告警。
2. **多模态深化**：视频抽帧 + 图像理解进入生成上下文，素材真正影响产物。
3. **加载与埋点**：播放/事件改异步聚合；bundle 走 CDN + 预取 + 骨架屏优化首屏。
4. **可观测运营化**：为现有 structlog/Sentry/OTel/LLM 账本补告警、采样策略和成本看板。
5. **生成质量**：扩大自由 codegen 比例，继续降低模板依赖，提升玩法多样性。
6. **引擎扩展（Unity）**：在 HTML5 / Three.js 之外接入 Unity WebGL，继续复用 `game-manifest/v1` 和 iframe 边界。
7. ⭐ **AI 生图素材**：在 `asset_processing` 接入文生图/图生图模型，替代当前本地占位素材。
