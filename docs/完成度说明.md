# 完成度说明

> 对应交付项「完成度说明（必选）」：逐项说明**已完成 / Mock 或简化 / 未完成**，以及**再给 1 周**的迭代计划。
> 配套文档：[系统架构](系统架构.md) · [数据模型与接口](数据模型与接口.md) · [Multi-Agent 设计](multi-agent_design.md) · [安全与可观测性](安全与可观测性.md)。

## 一句话总览

四条主链路（注册登录 / Create 生成 / 发布 / Home 浏览 / Play 远端加载）**全部端到端打通**，可在 `docker compose up` 后离线复现；核心加分项（社交、沙箱校验、真模型链路、3D）已实现；少数高成本隔离能力（容器级沙箱、内容审核）按 MVP 取舍留为可插拔的 Mock，接口边界已预留。

## 1. 已完成（可现场验收）

### 登录注册 Auth
- 邮箱注册 / 登录 / 退出；bcrypt 密码哈希 + JWT；前端 `localStorage` 持久化，刷新保活（挂载时 `GET /auth/me` 校验）。
- 受保护资源前后端双重守卫：后端 `Depends(get_current_user)`，前端 `/create`、`/me` 未登录重定向。
- 账号自助：改密、改资料、删号；登录校验 `is_active`；注册/登录 Redis IP 限流。
- **OAuth（加分）**：Google + GitHub **真实授权码流程**（`/auth/oauth/{provider}/start`+`/callback`）、`OAuthAccount` 账号绑定/合并 upsert、provider 探测；state 有时效并绑定浏览器 HttpOnly Cookie。未配置 provider 时默认禁用；固定共享身份的 demo 仅可通过 `ENABLE_OAUTH_DEMO=true` 在本地显式开启。

### 主页 Home
- 数据全部来自后端 `GET /games`（按 `status=PUBLISHED` 过滤），**非前端写死**（仅离线兜底数组）。
- 卡片字段齐全：封面 / 标题 / 作者 / 简介 / 标签 / 发布时间 / 播放数；**Create 来源游戏显示「✨ AI」角标**。
- 搜索、标签筛选、排序、「AI Generated」筛选；游戏详情页；点赞、收藏、播放次数统计。
- 测试数据：3 个已发布示例游戏，其中 **火线突围由真实 Create 流水线（GPT-5.5）生成**（`source=create`），满足「≥3、≥1 来自 Create」。

### 游玩 Play
- 按 DB meta 从对象存储（MinIO）**远端加载 `manifest.json` + bundle**，`iframe` 沙箱运行；接口返回 `_source:"oss"` / `oss://...` 可证明来自远端。
- 四态齐全：加载中 / 成功 / 失败（错误页 + 重试，非白屏）/ 退出（返回首页 / 重开）。
- 埋点：播放计数（30 分钟防刷）；游戏内 `postMessage` 上报分数 → 排行榜。

### 创建 Create（核心）
- 多模态输入：自然语言创意 + 文件/图片/视频上传，素材在生成任务中被引用（`asset_processing` 节点生成素材清单）。
- **Multi-Agent：LangGraph 真·多节点状态图（22 功能节点 + failed/done）**，含 `safety_intake → intent_spec → … → code_generation → build_validation → gameplay_qa → publish_artifact`，带 repair / replan 条件回边（非单次黑盒调用）。
- 任务状态 `pending/running/succeeded/failed` + 当前步骤；每步 `AgentStep` / `AgentLog` 持久化并前端实时展示（步骤流 + 活动日志 + token 计数）。
- 产物上传 OSS（`games/{id}/v1/`）+ 写 `manifest.json` + `Game`/`GameVersion` 入库；生成后可预览，发布后上首页。
- 加分：任务历史、失败重试、2D/3D 选择、生成成本（token）统计。

### 工程基础设施
- 远端产物协议 `game-manifest/v1`：`schema_version / entry / files[{path,url,sha256}] / permissions`。
- 安全/隔离：`iframe sandbox`（无 `allow-same-origin`）；生成代码**静态校验**（禁 `eval`/`fetch`/外链/`localStorage`）+ **V8 冒烟测试**（加载即崩溃自动回 coder 重生）；上传大小/类型校验；安全响应头；密钥仅服务端，前端只拿只读 URL。
- 数据库 PostgreSQL + SQLAlchemy + **Alembic 迁移**（`create_all` 兜底）。
- 测试/CI：`backend/tests` pytest（auth/games/tasks/uploads/social/限流）+ GitHub Actions（后端 pytest + 前端 `tsc`）。
- 部署：`docker compose`（web/api/worker/postgres/redis/minio）+ 生产 compose + Zeabur 指南 + 可选整站密码门禁。

## 2. Mock / 简化的部分（边界已预留，可平滑替换）

| 项 | 现状 | 边界 |
| --- | --- | --- |
| 服务端生成沙箱 | gVisor 容器为 **Mock**；实际用进程内 V8（`py_mini_racer`）做加载冒烟，无 cgroup cpu/mem 限制 | `agent_steps` 已为沙箱步骤留位，可替换为真容器执行 |
| 内容审核 / 病毒扫描 | 可插拔步骤，MVP 返回 `clean` | 接口边界保留，可接第三方服务 |

| 视频素材 | 仅存储 + 引用，未做抽帧理解（图片可进 vision） | 素材清单已含 `kind`，可加抽帧节点 |
| OAuth | 代码完整；默认未填密钥时禁用，开发环境可显式开启 demo | 填 client id/secret 即真授权；生产强制关闭 demo |
| 播放计数 | 同步写 DB | 可改异步事件聚合 |

## 4. 再给 1 周的迭代计划

1. **真隔离**：接真实容器沙箱（gVisor / Firecracker，`cpu=1 mem=256MB net=deny` 只读 FS 超时杀进程）+ 病毒/内容审核服务。
2. **多模态深化**：视频抽帧 + 图像理解进入生成上下文，素材真正影响产物。
3. **创作闭环**：版本管理 + Remix 派生（基于已有 `GameVersion`）。
4. **加载与埋点**：播放/事件改异步聚合；bundle 走 CDN + 预取 + 骨架屏优化首屏。
5. **可观测**：结构化日志 + OpenTelemetry 链路追踪 + 生成成本看板（已采集 token，做聚合面板）。
6. **生成质量**：扩大自由 HTML5 codegen 比例、降低模板依赖，提升玩法多样性。
7. **引擎扩展（Unity）**：在 HTML5 / Three.js 之外接入 Unity（WebGL 导出），`code_generation` / `build_validation` 节点增加 Unity 工程模板与构建步骤，支撑更复杂的 3D 玩法；产物仍走 `game-manifest/v1` 远端加载 + iframe 沙箱。
8. ⭐ **AI 生图素材（重点）**：在 `asset_processing` 节点接入文生图 / 图生图模型（SDXL / FLUX 等），按玩法生成贴图、精灵图、封面与 UI 素材，替代当前占位色块、显著提升画面美观度；生成素材随 bundle 上传 OSS 并写入清单。
